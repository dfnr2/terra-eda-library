# terra-dc_dc_converters 3D models

- `PCN1-S5-D15-S.stp`: CUI PCN1-S5-D15-S, downloaded 2026-11-06 from Bel Fuse's 3D model
  service (PARTcommunity/PARTserver, CADENAS). Licence CC BY-ND 4.0 (stated in the file's
  `FILE_NAME` header), terms: https://www.cadenas.de/terms-of-use-3d-cad-models.
  The file is kept unmodified (ND); placement is done by the footprint's model offset.
  It is the 5 V-input, dual-output body (19.5 x 6.1 x ~10 mm) and is used for the
  5 V and 12 V input PCN1-S footprint. The 24 V-input body is wider (7.2 mm) and has no model.
