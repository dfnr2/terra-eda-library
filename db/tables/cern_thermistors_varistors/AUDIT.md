## Tail derivation (device_type, voltage)
- [ ] `device_type` is derived from the CERN `LibSymbol` item name (deterministic,
      filled 53/53). The table cleanly splits on the symbol:
      `Thermistor NTC` → NTC (24), `Thermistor PTC` / `Thermistor PTC - polarized`
      → PTC (13), `Varistor` → Varistor (15), `TCO Resistor + Fuse` → TCO (1).
      `Component Type`/`Component Kind` are uniformly `Standard` (useless); the
      symbol name is the clean type dimension here.
- [ ] `voltage` copied verbatim from the CERN `Voltage` column (37/53 filled; e.g.
      `460VAC`, `650V`, `250VAC`). Mostly the varistors' working/clamp voltage;
      sparse for thermistors (which have no meaningful clamp voltage). The core
      `value` column carries the CERN `Value` (resistance for thermistors, a
      free-text description for varistors where Value is blank — value 53/53).
- [ ] No resistance/B-value column: thermistor resistance is already in `value`
      (CERN `Value`); the B-constant and other parametrics live only in free-text
      descriptions, not deterministically parseable, and absent from the symbol
      names.

## 3D model coverage
- [ ] 12/53 parts (~22%), 8 footprints, via the new thermistor/varistor rule in
      tools/model_map.py (`_resolve_thermistor_varistor`, wired into
      `resolve_from_footprint`): dimensioned SMD chip-body footprint names
      (`THERMC<LLWW>X..`, `VAR_<LLWW>X..` — 1608/2013/3216/3225/3220/1005 in
      0.1mm) → nearest KiCad `R_<size>_<metric>` Resistor_SMD chip model (a
      thermistor/varistor chip shares the resistor chip body). The CERN `Case`
      column also carries the size, but it collides with the diode chip keys in
      SMD_PACKAGE_MODEL, so — like fuses — these footprints resolve purely from
      the footprint name (apply_3d_models routes THERM*/VAR* names to the chip
      resolver, never the package path). Locked by 2 new cases in
      tests/test_model_map.py.
- [ ] Residual ~78% is expected, not a regression: bespoke leaded/disc/metal
      bodies (THERM_<mfr>_* inrush NTCs Ametherm SL08/SL12/SL22, TDK B57xxx
      leaded, Murata PRF15/PRG18 chip-but-bespoke-footprint, Ohmite TX08, EPCOS
      B75x/B57153S0; VAR_<mfr>_* EPCOS/TDK B72xxx disc varistors, Littelfuse
      SM20/V8ZA1P, Wurth 820412711), the metal THERMM10080X380N (10.0x8.0mm body —
      no chip model), and the lone TCO/polarized-PTC footprints (TCO_TDK-LAMBDA,
      TEXAS_DYA0002A) — KiCad ships no matching bundled model. These go to the
      human drop-folder under kicad_3dmodels/.
- [ ] The bespoke names never mis-resolve: the chip resolver requires the
      dimensioned `THERMC`/`VAR_<dims>` token, so `THERM_MURATA_PRF15` (Case 0402
      but bespoke footprint) and `THERMM10080X380N` decline rather than borrowing
      a wrong chip body.
