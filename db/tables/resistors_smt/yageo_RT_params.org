* Overview
This document summarizes the Yageo *RT series* thin-film chip resistors, including:

1. A precise, LLM-friendly description of the *global part number format*.
2. Tables covering the *±0.1%, ±0.5%, and ±1%* tolerance grades for *50 ppm/°C* TCR, sizes *0402 through 2512*.
3. Includes: size, tolerance, tempco, power rating, maximum working voltage, maximum overload voltage, and valid resistance range.

All information is taken from the Yageo RT-series datasheet (Mar 13, 2023, V1.5).

* Global Part Number Structure

The global part number format is:

#+begin_example
RT [SIZE4] [TOL] [PACK] [TCR] [TAPE] [RV_CODE] L
#+end_example

** Field Definitions

| Field     | Meaning |
|-----------+-------------------------------------------------------------|
| RT        | Series identifier (thin-film RT resistors)                 |
| SIZE4     | 4-digit imperial package size                              |
| TOL       | Tolerance code                                             |
| PACK      | Packaging type                                             |
| TCR       | Temperature coefficient of resistance code                 |
| TAPE      | Taping reel code                                           |
| RV_CODE   | Encoded resistance value using R/K/M as decimal markers    |
| L         | Default ending code (order only)                           |

** Resistance Value Encoding (RV_CODE)

General rules:

- 2–4 characters
- R, K, M act as decimal points
- No final zero after the unit letter:
  - ~1K2~, not ~1K20~
  - ~97R6~, not ~97R60~

Examples by range:

| Range         | Pattern | Example |
|---------------+---------+---------|
| 1–9.76 Ω      | XRXX    | 1R5     |
| 10–97.6 Ω     | XXRX    | 47R5    |
| 100–976 Ω     | XXXR    | 100R    |
| 1–9.76 kΩ     | XKXX    | 9K76    |
| 1–9.76 MΩ     | XMXX    | 1M00    |

** Example Part Number
RT0603DRE0756RL

Decomposed:
- RT = series
- 0603 = size
- D = ±0.5%
- R = paper tape
- E = 50 ppm
- 07 = 7" reel
- 56R = 56 Ω
- L = default suffix

* Electrical Characteristics (TCR = 50 ppm/°C)
Values are identical across 0.1%, 0.5%, and 1% tolerance grades for a given size.

** Legend
- PR = Power Rating
- MWV = Max Working Voltage
- MOV = Max Overload Voltage
- Range = Resistance Range (for ±0.1%, ±0.5%, ±1%, 50 ppm)
